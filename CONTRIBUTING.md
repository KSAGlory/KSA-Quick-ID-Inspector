# Contributing

Thanks for helping improve KSA Quick ID Inspector. Bug reports, compatibility notes and focused code improvements are welcome.

## Reporting a bug

Before opening an issue:

1. Confirm that you are using GTA San Andreas 1.0 US and CLEO 4.4 or newer.
2. Test the latest release of the mod.
3. Check whether the problem still happens without unrelated gameplay mods.

Include the following information in your report:

- Your game, CLEO and Mod Loader versions
- How the mod was installed
- Clear steps that reproduce the problem
- What you expected to happen and what happened instead
- Relevant lines from `cleo.log` or `modloader.log`

Remove usernames, personal paths and other private information from logs before posting them.

## Pull requests

Keep each pull request focused on one change. Explain why the change is useful and describe how you tested it. Avoid unrelated formatting changes, bundled tools and optional dependencies.

The source script is in `src/KSA_Quick_ID_Inspector.txt`. Open it in Sanny Builder 4.2 or newer, select `GTA SA (v1.0 - SBL)`, and compile it before testing.
