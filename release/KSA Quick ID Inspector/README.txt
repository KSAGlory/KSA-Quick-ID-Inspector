REQUIREMENTS
GTA San Andreas 1.0 US
CLEO 4.4 or newer
Mod Loader is recommended

MOD LOADER INSTALLATION
Copy the "KSA Quick ID Inspector" folder into your game's modloader folder.

DIRECT INSTALLATION
Copy cleo\KSA_Quick_ID_Inspector.cs into your game's cleo folder.

USAGE
Aim at a pedestrian to see their model ID and health.
Sit inside a vehicle to see its name, model ID and health.
Type KSAID during gameplay to enable or disable the inspector.

The mod does not modify save files.
